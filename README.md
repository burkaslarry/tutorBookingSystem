# AI 課程預約及簽到

一個供補習中心前台使用的預約管理系統。可新增學生預約、查看指定日期的課堂名單，並在學生到達時更新簽到狀態。資料會儲存於本機 SQLite 資料庫。

## 使用方式

需要 Node.js 22.5 或更新版本。在專案目錄執行（啟動指令已包括內建 SQLite 所需設定）：

```sh
npm start
```

然後開啟 [http://localhost:8000](http://localhost:8000)。首次啟動時會建立 `data/bookings.db`；舊版本存在瀏覽器的預約會在資料庫為空時自動搬移。

執行測試：

```sh
npm test
```

## 功能

- 新增學生、聯絡電話、AI 課程、日期及時間預約
- 查看每日預約、待簽到及已簽到人數
- 按日期和簽到狀態篩選預約
- 手機版提供儀表板、預約及新增預約底部導覽
- 學生到達後簽到；亦可取消或還原預約
- 將未取消的預約匯出為 `.ics`，匯入 Google 日曆
- 使用 SQLite 持久儲存，重新啟動或清除瀏覽器資料不會遺失預約

## Google 日曆

按「匯出 .ics」下載目前所有未取消的預約，再在 Google 日曆的「設定 > 匯入及匯出」匯入該檔案。每個課堂會建立為一小時的日曆事件。這是單向檔案匯出，不會自動同步；更改預約後請重新匯出，並留意重複匯入可能建立重複事件。

即時 Google Calendar OAuth 同步仍需要專用 Google 帳戶的 OAuth Client ID、Client Secret 和 Calendar ID。設定清單及安全交收方式見 `Whatsapp.md`；Client Secret 不應放進前端程式碼或提交到 Git。

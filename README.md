# AI 課程預約及簽到

一個供補習中心前台使用的簡易預約管理頁面。可新增學生預約、查看指定日期的課堂名單，並在學生到達時更新簽到狀態。

## 使用方式

直接以瀏覽器開啟 `index.html`。預約資料儲存在目前瀏覽器的 `localStorage`，因此只會在同一部裝置及瀏覽器使用；清除瀏覽器資料會移除已儲存的預約。

## 功能

- 新增學生、聯絡電話、AI 課程、日期及時間預約
- 查看每日預約、待簽到及已簽到人數
- 按日期和簽到狀態篩選預約
- 手機版提供儀表板、預約及新增預約底部導覽
- 學生到達後簽到；亦可取消或還原預約
- 將未取消的預約匯出為 `.ics`，匯入 Google 日曆

## Google 日曆

按「匯出 .ics」下載目前所有未取消的預約，再在 Google 日曆的「設定 > 匯入及匯出」匯入該檔案。每個課堂會建立為一小時的日曆事件。這是單向檔案匯出，不會自動同步；更改預約後請重新匯出，並留意重複匯入可能建立重複事件。
